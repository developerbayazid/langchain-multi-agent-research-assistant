# 🔎 LangChain Multi-Agent Research Assistant

An AI-powered research assistant built with **LangChain, OpenAI, Tavily, and Streamlit**. It searches the web for relevant information, reads selected webpages, generates a structured research report, and reviews the report using a critic chain.

The project uses a simple Python-based pipeline to orchestrate the research process.

## ✨ Features

- **Web Search Agent:** Finds relevant information and research sources.
- **Reader Agent:** Scrapes selected webpages and extracts useful content.
- **Research Writer:** Generates structured reports from gathered information.
- **Critic Chain:** Evaluates reports and provides strengths, improvement suggestions, and a score.
- **Streamlit UI:** Provides a clean, Claude-inspired chat interface in the browser.
- **Processing Status:** Displays the active research stage and elapsed processing time.
- **Research History:** Displays previous interactions during the current Streamlit session.
- **Source Visibility:** Allows users to inspect the search results and scraped content.

## 🏗️ Architecture

The application follows a sequential research pipeline:

```text
User Research Topic
        |
        v
   Search Agent
        |
        v
   Reader Agent
        |
        v
   Writer Chain
        |
        v
   Critic Chain
        |
        v
 Final Research Report
 + Critic Feedback
```

### Components

| Component       | Responsibility                                        |
| --------------- | ----------------------------------------------------- |
| Search Agent    | Searches the web using the configured search tool     |
| Reader Agent    | Reads relevant webpages using the scraping tool       |
| Writer Chain    | Creates a structured research report                  |
| Critic Chain    | Reviews the report and suggests improvements          |
| Streamlit       | Provides the browser-based user interface             |
| Python Pipeline | Coordinates the agents and passes data between stages |

2. Python compatible with the project's dependencies.

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/developerbayazid/langchain-multi-agent-research-assistant>
cd langchain-multi-agent-research-assistant
```

Replace `<YOUR_REPOSITORY_URL>` with your actual repository URL.

If you already have the project locally, open a terminal in the project directory instead.

### 2. Install dependencies

```bash
uv sync
```

This installs the dependencies declared in `pyproject.toml` and uses the project's lockfile when available.

### 3. Configure environment variables

Create a `.env` file in the project root:

```dotenv
OPENAI_API_KEY=your_openai_api_key
TAVILY_API_KEY=your_tavily_api_key
```

Replace the placeholders with your actual credentials.

The Tavily variable is required only if your search implementation uses Tavily and expects that environment variable.

**Security:** Never commit `.env` or expose API keys in source code, screenshots, logs, or public repositories.

Make sure `.env` is included in `.gitignore`.

## ▶️ Running the Application

### Option 1: Streamlit web interface

Run the following command from the project root:

```bash
uv run streamlit run app.py
```

Open the local URL shown in the terminal. Streamlit commonly uses:

```text
http://localhost:8501
```

Enter a research topic in the chat input and wait for the research pipeline to finish.

The interface can display:

- The active research stage.
- Elapsed processing time.
- The generated research report.
- Critic feedback.
- Search results and scraped content.

### Option 2: Run from the terminal

Run:

```bash
uv run python main.py
```

The terminal entry point executes the research pipeline with the topic configured in `main.py`.

To research a different topic, update the topic string in that file.

## 🔄 Research Workflow

### Step 1: Search

The Search Agent receives the research topic and uses the configured web search tool to find relevant sources.

### Step 2: Read

The Reader Agent examines the search results, selects relevant URLs, and uses the webpage scraping tool to gather more detailed information.

### Step 3: Write

The Writer Chain combines the search results and scraped content to generate a structured report containing:

- Introduction
- Key Findings
- Conclusion
- Sources

### Step 4: Critique

The Critic Chain evaluates the report and produces:

- Score out of 10
- Strengths
- Areas to Improve
- One-line Verdict

The current implementation returns the critique separately. It does not automatically revise the report based on the critic's feedback.

## 🧠 How the Pipeline Works

The pipeline passes information between stages using a Python dictionary:

```python
state = {
    "search_results": "...",
    "scraped_content": "...",
    "report": "...",
    "feedback": "...",
}
```

Each stage adds its output to the state, making that information available to subsequent stages.

The pipeline is implemented using ordinary Python function calls and LangChain agent/chain invocations.

**LangGraph is not required by the current implementation.** It can be introduced later to manage graph-based state, conditional routing, agent handoffs, and iterative report improvement.

## ⏱️ Processing Status

The Streamlit interface can show elapsed time while the research pipeline is running.

For example:

```text
Searching the web...
Processing · 3s

Reading and analyzing webpages...
Processing · 12s

Writing your research report...
Processing · 25s

Reviewing report quality...
Processing · 34s
```

The timer represents actual elapsed time, not a percentage-complete estimate.

Stage updates depend on progress callbacks being implemented in the pipeline. The elapsed time varies with API response times, network conditions, the number of pages read, and model processing time.

## 🐛 Troubleshooting

### `TypeError: create_agent() got an unexpected keyword argument 'llm'`

Use `model=llm` rather than `llm=llm` when calling `create_agent()` with the LangChain API used by this project.

```python
agent = create_agent(
    model=llm,
    tools=[web_search],
)
```

### Missing API key

Check that:

- The `.env` file exists in the project root.
- The environment variable names match what your code expects.
- `load_dotenv()` runs before initializing clients that need those variables.
- Your API keys are valid.

### Search or scraping errors

Inspect `src/tools/tools.py` and verify that:

- The tools are correctly defined.
- The search tool returns useful results.
- URLs are passed to the scraping tool in the expected format.
- The websites allow access and return readable content.

### Streamlit does not start

Run:

```bash
uv sync
uv run streamlit run app.py
```

If the error persists, check the terminal traceback and confirm that `app.py` is in the project root.

## 🔐 Security Notes
