# Taste

## Workflow & collaboration
- Wants root-cause analysis and an explicit explanation of the bug first, and no code edits until they approve — states this directly ("analyze those files and let me know what is issue before changing anything ask me please"). Confidence: 0.85
- Prefers being presented with concrete fix options and making the call themselves rather than receiving a single unilateral fix. Confidence: 0.7

## Tooling
- Uses `uv` for Python projects (e.g. `uv run python main.py`) inside a Windows PowerShell environment (`PS C:\...>` prompts, Windows-style paths in errors). Confidence: 0.7
